## 不做的項目

| 項目 | 原因 |
|---|---|
| 上架 Google Play | 倬自用；無障礙截圖用途也不易過審 |
| 使用 xAI Grok API | 倬更正為 Groq；xAI 開發者 API 無免費額度 |
| MediaProjection 截圖 | Android 14 起每次都要確認，狀態列一直有錄影圖示 |
| 背景自動截圖／持續翻譯 | 隱私與額度考量；只在點擊或翻頁後翻譯（原因待倬確認是否同意列為「不做」） |
| 多個 Groq 帳號輪替 | 違反使用條款 |
