## 元件規則
- 設定頁全部用 Material 3 元件（Card、FilterChip、Switch、Slider、OutlinedTextField），深色主題。
- 選項少於 5 個用 FilterChip 橫列（可橫向捲動）；開關用 Switch；數值用 Slider 並在右側顯示目前值。
- 每個引擎都有「測試翻譯」與「模型列表」按鈕；結果用 Teal（成功）／Rose（失敗）顯示在按鈕下方。
- API key 欄位預設遮蔽，右側眼睛圖示切換顯示。
- 小圓點與疊加層用自繪 View，不用 Compose（無障礙疊加層視窗）。
- 錯誤一律用 Toast 或頁面文字顯示原因，不靜默失敗。
